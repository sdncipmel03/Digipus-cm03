# Digipus - SDN Cipinang Melayu 03 Pagi
### Aplikasi Perpustakaan Digital Edukatif & Ramah Anak

Sistem informasi perpustakaan digital untuk SDN Cipinang Melayu 03 Pagi dengan integrasi otomatis ke **Google Sheets** dan subfolder **Google Drive**.

## 🚀 Cara Menjalankan Cepat
1. **Buka di Komputer Ini**: Klik dua kali file `Buka_Digipus.bat` di Windows.
2. **Akses dari Komputer Lain (Wi-Fi Sekolah)**: Klik dua kali file `Bagikan_Ke_Komputer_Lain_WiFi.bat` lalu buka alamat IP yang tertera di komputer guru/siswa lain.
3. **Login Admin**: Klik tombol "Login Admin" di pojok kanan atas (Username: `admin`, Password: `admin123`).
4. **Panduan Lengkap Setup Google Drive & Deploy Online**: Buka file [PETUNJUK_LENGKAP.md](file:///c:/Users/admin/OneDrive/Documents/APLIKASI/Aplikasi%20Perpustakaan/PETUNJUK_LENGKAP.md).

## 🌟 Fitur Utama
- **Katalog Buku Lengkap**: Kategori Fiksi, Non-Fiksi, Pelajaran Tematik, Kamus/Referensi, Agama.
- **Buku Fisik & Digital**: Upload file PDF E-Book langsung ke Google Drive subfolder `Ebook_Files`.
- **Sirkulasi Peminjaman & Pengembalian**: Penghitungan masa tempo 7 hari dan 1-klik pengembalian yang memperbarui stok otomatis.
- **Buku Tamu Kunjungan**: Rekap kehadiran pengunjung siswa dan guru.
- **Laporan & Rekap Bulanan PDF**: Format standar kedinasan dengan Kop Surat SDN Cipinang Melayu 03 Pagi dan tanda tangan Kepala Sekolah & Pengelola Perpustakaan.
- **Dashboard Statistik**: Dilengkapi Chart.js untuk distribusi kategori dan buku terpopuler.
- **Pengaturan & Upload Logo**: Upload logo sekolah langsung ke Google Drive subfolder `School_Assets`.
